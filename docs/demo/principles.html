PRINCIPLE 01

A pure core,
a thin shell.

The shell touches the world — loads, appends, publishes. The core only sees data and returns events.

"No clock, no I/O, no randomness" isn't a slogan — it means every input is an explicit argument. Same arguments → same money, every time.
decide(state, command) → events · the database never calls the core
the boundary, the right way round · and what "pure" means
shell · load + foldPostgres → state → PURE CORE · decide()no clock · no I/O · no random → shell · append + publishPostgres · Redpanda
❌ impure ✓ pure
// ❌ hidden inputs — two runs can disagree Money Interest(Deposit d) => d.Principal * RateOn(DateTime.UtcNow) // ← clock * _db.LoadDayCount(d.Id) // ← I/O * Jitter(Random.Shared); // ← randomness
// ✓ every input explicit — same args, same money static Money Interest( Money principal, Rate rate, int days) => principal.Times(rate).ForDays(days, Basis.Act360); // clock, db, random → lifted out to the shell
PRINCIPLE 02

State is just fold(events).

So replay is deterministic: two lanes, same log, different speeds — both fold to a byte-identical state hash. Timing doesn't matter; the function is pure.

API appends → append-only log → fold → position
fold([#1 Constituted, #2 InterestPaid, #3 InterestPaid, #4 Matured]) → position
lane A (fast) → state hash d2a…9f7c
lane B (slow) → state hash d2a…9f7c
✓ byte-identical — determinism, not timing
append via API → log → fold
PRINCIPLE 03

The engine doesn't know what a
term deposit is.

The spine is generic. A product family plugs in as a module — events, folds, lifecycle, decider.

Adding a family is one composition line and zero edits to the kernel, store, or bus.

PRINCIPLE 04

No PII on the bus.
Forget by shredding a key.

The bus carries a reference, never the person. PII is encrypted and resolved only inside the engine boundary.

GDPR erasure isn't a hunt across every topic and backup. Shred one key → every copy, everywhere, is undecryptable at once.

Why it composes

Five choices. One property.

A pure core makes replay deterministic. Determinism makes the log the truth. A generic spine lets families plug into that truth. The PII boundary keeps it lawful. The drift gate keeps the record honest as it grows.
