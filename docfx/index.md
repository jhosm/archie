# babelstone — C# API Reference

The C# API surface of the event-sourced product engine (`engine/`) and the domain
family handlers (`families/`), generated from the source XML doc comments
(ADR-PC-026). Open it from the **API Reference** entry in the top navigation —
namespaces, types, and members of the engine kernel and the family handlers.

This site is **only** the C# API reference. The hand-authored documentation corpus
— the three concern-axis series (financial, product, integration concepts), both
ADR namespaces, the generated contract reference, and the config-author product
docs — is **not** published here. It lives in the repository and renders on GitHub,
where every cross-link resolves against the tree at the revision you are viewing:
**[browse the docs on GitHub](https://github.com/jhosm/babelstone/tree/main/docs)**.
