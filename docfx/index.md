# babelstone

A Portuguese banking ecosystem reference — architecture and financial-concept docs
alongside a working, event-sourced C# product engine.

- **[Document map](../README.md)** — the three concern-axis doc series
  (financial, product, integration concepts), both ADR namespaces, and the
  generated contract reference.
- **API Reference** (top navigation) — the C# API surface of `engine/` and
  `families/`, generated from XML doc comments (ADR-PC-026).
