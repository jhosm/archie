Catalogue portal — static-site host

This is the local catalogue portal static-site host (P.5). It serves whatever static site is built into this directory.

No portal yet. Epic G.4 (PR #110) superseded ADR-IC-008 (EventCatalog) with ADR-IC-015: the chosen portal is now Backstage, and the portal-host deployment is explicitly deferred to platform work (bd babelstone-s4ol.1). What G.4 did ship is the governance layer that never depended on a portal — the AsyncAPI source files under contracts/catalog/events/, the Backstage catalog-info.yaml descriptor, and the hermetic CI gate (scripts/asyncapi-catalog-validate.sh). Until the Backstage host lands, the estate operates Git-native (files + gate + GitHub's renderer), the fallback posture ADR-IC-015 §9 records. This nginx host (P.5) is only the serving mechanism, kept ready for whatever static portal is built here.

Spec format: AsyncAPI 3.0 (one file per integration event, version-controlled alongside the Avro schema, ADR-IC-002). Portal: Backstage (Apache-2.0, CNCF-graduated), which imports the same AsyncAPI files — host deployment deferred per ADR-IC-015 §9.
