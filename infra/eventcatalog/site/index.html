EventCatalog — static-site host

This is the local EventCatalog static-site host (ADR-IC-008). It serves whatever static site is built into this directory.

No catalog yet. The EventCatalog build — importing the AsyncAPI specs that describe each integration event — is produced by Epic G.4, which writes its static output here. This host (P.5) is only the serving mechanism, mirroring how the OCI registry hosts packs whose content arrives with Epic C.4/C.5.

Spec format: AsyncAPI (one file per integration event, version-controlled alongside the Avro schema). Portal: EventCatalog, built to static HTML and served from here.
